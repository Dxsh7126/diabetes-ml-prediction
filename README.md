# Diabetes Progression Prediction using Machine Learning

This project demonstrates a beginner-level machine learning workflow using **Simple Linear Regression** to predict diabetes disease progression based on a single feature (BMI) from the scikit-learn diabetes dataset.

---

## 📌 Project Overview

- Dataset: scikit-learn diabetes dataset
- Feature used: BMI (standardized feature from dataset)
- Model: Simple Linear Regression
- Tools: Python, scikit-learn, NumPy, Pandas, Matplotlib

---

## 🔍 Approach

1. Load the diabetes dataset using scikit-learn
2. Select BMI as the input feature
3. Split data into training and testing sets
4. Scale features using StandardScaler
5. Train a Linear Regression model
6. Evaluate performance using MSE and R² score
7. Visualize predicted vs actual values

---

## 📈 Results

- The model was evaluated using Mean Squared Error (MSE) and R² score
- A scatter plot was used to compare predicted and actual values

---

## 🧠 Learning Outcomes

- Understanding of simple linear regression
- Feature selection and scaling
- Model training and evaluation
- Visualizing regression results
